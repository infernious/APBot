# Scam detector v2.2: seven-day timeout

Preserves all v2.1 image-only detection rules, legacy scanner archive and queue/resource limits. When enforcement is explicitly enabled, a confirmed matching message is audited privately, revalidated and deleted. Only after confirmed deletion does the bot fetch the current member, verify staff immunity, role hierarchy, permissions, configuration and audit availability, then apply a native seven-day Discord timeout with audit reason `Scam`. No ban, no infraction points, no history-wide purge, no new dependencies or database writes. Every separately confirmed queued image message can be deleted. A timeout at least 6 days 23 hours 55 minutes remaining is preserved to avoid extending a burst repeatedly; longer timeouts are never intentionally shortened. A concurrent human timeout change between fetch and update cannot be made atomic. If a timeout fails or cannot be verified, the message deletion outcome and timeout outcome are recorded separately in the private audit embed and application log.

Dry-run defaults to true and performs neither deletion nor timeout. On the test guild only, use `scam_detector_dry_run: false` to test enforcement on a non-staff test member. Bot requires Manage Messages in source channels, Moderate Members at guild level and a higher role than the test member; private review channel remains mandatory. Live Nextcord integration and OCR inference must still be checked. No automatic escalation to a ban.

Run `python -m pytest tests/test_scam_image_detector.py tests/test_scam_timeout.py -q`. The original 85 archived tests and 23 new tests passed using the local Nextcord stub. Local test counts may differ.

# Scam detector v2.4: review-only test mode

Set `scam_detector_test_mode` to true on the existing testing bot (1263186086260244520) in the testing guild (1498714554983645207). Set `scam_detector_dry_run` to true and `scam_detector_review_channel_id` to the numeric ID of a private review channel in that guild. If the test-mode flag is true with a different bot or guild, the detector refuses to scan there. Test mode includes staff, posts ordinary (non-spoiler) matching image attachments with the first displayed in the embed, and never deletes, times out or bans. It groups matching images from each message, splitting uploads at 8 MiB. Up to six eligible images are scanned per message, within the existing 45-second scan budget; partial matches can still be reported on budget exhaustion. Existing queue caps and overload logging remain. Only matching images are forwarded. The log channel must be private and the bot needs Attach Files, Send Messages, Embed Links and View Channel. Text-only and unrelated images are ignored. In production (test_mode false or absent), staff exemptions and the existing dry-run/enforcement behavior remain; the enforcement evidence is no longer spoilered. Do not enable enforcement until live testing is complete. Legacy scanners are unchanged.

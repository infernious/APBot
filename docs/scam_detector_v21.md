# Scam detector v2.1: image-only campaign moderation

Only supported uploaded still image attachments (PNG, JPEG, WebP, BMP) are inspected. Text, URLs, captions, videos, GIFs and generic scam/NSFW/QR categories never independently cause deletion. Staff and bots are exempt. Captions can indicate that an image is being reported, in which case the message is retained. No external AI services or new dependencies.

Three detection paths: exact SHA-256 of a supplied campaign screenshot; strict near-copy comparison (aspect ratio, horizontal and vertical 256-bit difference hashes, 256-bit average hash); local OCR of a single image with corroborating MrBeast or Donald Trump first-person casino promotion indicators, or known campaign domain plus withdrawal/bonus indicators. Domainless payout images only qualify as known/near copies. No original screenshots or user wallet details are shipped. Other celebrity promotions are not targets. OCR failure, missing permissions or overloaded/expired queue fails open. Novel/cropped/edited images, deliberate adversarial changes, or closely similar benign screenshots are limitations. No automatic ban.

One bounded queue (8 waiting), one OCR child process, 15s timeout, 45s scan budget, 8 MiB/file, 12M pixels, 6 images/message, 256 cached verdicts. OpenCV/ONNX threads limited to one, Unix worker niceness +10, idle child stops after 60s. Fingerprint comparisons happen before OCR engine initialization. Private audit channel required before deletion, and the message is fetched again before action; Discord cannot make check-and-delete atomic. Logs store reason, IDs, and fingerprint, not image copies. Legacy source/tests are inactive in `legacy/scam_detector_v1/`; no config, startup, database, or dependencies changed by the installer.

## Local setup
Use the existing test bot config and review channel. Defaults to dry-run; for actual local deletion testing set `scam_detector_enabled: true` and `scam_detector_dry_run: false` as top-level JSON fields. Override `scam_detector_review_channel_id` if necessary; channel must be private, with bot View Channel, Send Messages and Embed Links. Bot must have Manage Messages in source channels. Keep production dry-run until live testing and review.

Run `python -m pytest tests/test_scam_image_detector.py -q` in the repo root. 85 tests passed in a Nextcord-stub environment. Actual subprocess near-copy path matched 40 transformed images (8 supplied files x 5 resize/JPEG combinations); 8/8 exact hashes matched, 0/75 other local screenshots matched visual fingerprints. These are not independent accuracy estimates. Real Nextcord and RapidOCR inference remain untested here. Live-test a non-staff account posting original and transformed images, benign images, text-only copies, video/GIF, staff posts and scam warnings. Check audit, CPU/memory and queue behavior. No guarantee of 100% detection or zero bugs.
